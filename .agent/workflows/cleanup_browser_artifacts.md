---
description: Clean up temporary browser artifacts (cache, local storage) and ensure they are removed from the git repository.
---

This workflow helps you clean up temporary files generated by browser automation tools and ensures your git repository remains clean.

1. **Remove Local Cache Directories**
   Execute this PowerShell command to delete common browser artifact directories.
   // turbo
   ```powershell
   Remove-Item -Path "CachedData", "cache", "Code Cache", "Crashpad", "DawnGraphiteCache", "DawnWebGPUCache", "GPUCache", "Local Storage", "Network", "Session Storage", "Shared Dictionary", "blob_storage", "Local State", "Preferences", "SharedStorage", "DIPS" -Recurse -Force -ErrorAction SilentlyContinue
   ```

2. **Update .gitignore**
   Check the `.gitignore` file. If the following lines are missing, append them to the end of the file:
   ```gitignore
   # Browser Artifacts
   CachedData/
   Crashpad/
   Local Storage/
   GPUCache/
   DawnGraphiteCache/
   DawnWebGPUCache/
   Code Cache/
   Session Storage/
   Shared Dictionary/
   Network/
   blob_storage/
   Cookies/
   Network Persistent State/
   Preferences/
   TransportSecurity/
   Local State/
   SharedStorage/
   DIPS/
   ```

3. **Clean Git Index**
   Remove the ignored files from the git index to ensure they are tracked as deleted in the repository.
   // turbo
   ```bash
   git rm -r --cached .
   ```

4. **Commit and Push Changes**
   Re-add the correct files, commit the cleanup, and push to remote.
   ```bash
   git add .
   git commit -m "chore: clean up browser artifacts"
   git push
   ```
